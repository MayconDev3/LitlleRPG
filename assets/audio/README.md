# Áudio original de Little RPG

Os arquivos WAV deste diretório são gerados por `tools/audio.py` sem amostras externas. Podem ser usados, editados e publicados neste projeto pelo proprietário. Não contêm gravações ou composições extraídas de Zelda, Sword Art Online ou outras obras.

Importe os cinco arquivos para sua conta Roblox, permita o uso na experiência e preencha `C.Audio` em `src/shared/Config.lua` / ReplicatedStorage.LittleRPG.Config. Os arquivos locais não são reproduzidos automaticamente pelo motor Roblox.
